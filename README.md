# BigShare Telegram Bot

Automated adult video posting system with BigShare integration and Telegram bot.

## Features

✅ Auto-detect videos in file store channel  
✅ Support both video files and direct download links  
✅ Automatic upload to BigShare API  
✅ Thumbnail extraction with FFmpeg  
✅ Queue-based scheduled posting  
✅ Customizable posting intervals  
✅ Complete statistics dashboard  
✅ Admin commands for full control  
✅ MongoDB database for tracking  
✅ Customizable caption templates
